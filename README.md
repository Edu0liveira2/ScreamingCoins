# 🎮 Screaming Coins

Screaming Coins é um jogo 2D feito na Unity onde o objetivo é coletar moedas que… gritam 👀
Cada moeda emite um som ao ser coletada, criando uma experiência simples, divertida e um pouco caótica.

---

## 🕹️ Como Jogar

Use o teclado para controlar o personagem:

W / ↑ → mover para cima
S / ↓ → mover para baixo
A / ← → mover para a esquerda
D / → → mover para a direita

---

## 🎯 Objetivo

* Explore o mapa
* Encontre todas as moedas
* Colete todas elas para vencer o jogo

Quando todas as moedas forem coletadas, o painel de fim de jogo aparecerá.

---

## 🔊 Mecânica Principal

* Cada moeda emite um som ao ser coletada
* O áudio pode exigir interação (clique na tela) na versão web

---

## ⚠️ Dicas

* Certifique-se de explorar todo o mapa
* Não deixe nenhuma moeda para trás

---

## 🧱 Tecnologias Utilizadas
